Bookley is a web application for discovering, browsing, and managing books. It allows users to search for books, view detailed information, and explore collections. 


![alt text](image.png)
---

## Features

- Browse and search books by title, author, or category.
- View detailed book information including:
  - Title, author(s), publisher
  - Description and categories
  - Language, average rating, page count
  - Preview links and cover images
- Responsive and interactive design with dynamic book cards.


---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
